# Computer Vision and Image Processing Labs

Hands-on lab notebooks for computer vision and image processing in Python.

## Contents

- `module2/image_processing_with_pillow.ipynb` — Image processing with the Pillow (PIL) library: loading and displaying images, grayscale conversion, quantization, working with RGB color channels, and converting images to NumPy arrays.

## Requirements

- Python 3.12
- Packages:

```bash
pip install Pillow matplotlib numpy jupyterlab ipykernel
```

## Running the labs

```bash
jupyter lab
```

Then open a notebook from the `module2/` folder and run the cells top to bottom.

The lab images (`lenna.png`, `baboon.png`, `barbara.png`) are downloaded automatically by a cell in the notebook, so they are not tracked in this repository.
